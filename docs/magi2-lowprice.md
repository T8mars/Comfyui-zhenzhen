# Magi 2 视频（平价小屋）

更新后重启 ComfyUI 并刷新浏览器，搜索 `Magi 2`。在同一个节点内选择国内 `magi-2` 或海外 `magi-2-global`，把平价小屋 API Settings 的 `api_config` 接入节点。两个模型使用相同的参数。参见 [平价小屋 API 文档](https://api.seedance.nz/docs/llms.txt)。

| 模式 | 输入 |
| --- | --- |
| `auto` | 没有素材时文生；只有 1–2 张图时使用首尾帧；有视频、音频或至少 3 张图时使用参考模式。 |
| `text` | 只填提示词，不接素材。 |
| `frame` | `image1` 接首帧，`image2` 可接尾帧。不接音频或视频。比例选择 `api_default` 时跟随首帧。 |
| `reference` | 最多 10 张图、5 段视频、5 段音频。只有 1–2 张角色或风格图时，也显式选这个模式。单段视频或音频为 2–30 秒，视频和音频各自合计不超过 30 秒。 |

所有模式都填提示词，输出固定 1080p、4–30 秒，可开关生成音频。节点输出 ComfyUI 的 `VIDEO`，可直连 `SaveVideo`；并发版接 `并发接收视频`。

## 示例

在 `workflow/` 搜索 `zhenzhen-magi-2`：国内和海外各有文生（`t2v`）、首尾帧（`i2v`）、混合参考（`r2v`）和参考并发示例，共 8 份。示例不含密钥，有加载节点的示例需先选择本地素材。

## 验证

- 用本插件新提交国内首尾帧任务，成功下载并解码 1920×1080、120 帧的 MP4。用同一渠道 Key 查询参考项目已提交的国内文生、海外混合参考任务，也分别取得并解码了相同规格的视频，未重新创建这两条任务。
- 8 份示例均通过 ComfyUI 画布加载、缩放和重载。普通与并发节点各验证 10 路图像、5 路视频、5 路音频按连接逐路展开。
