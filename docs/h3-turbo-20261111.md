开发日期：2026-11-11。参考项目为本地ComfyUI_Seedance；参数核对[最新API文档](https://api.seedance.nz/docs/llms.txt)的“MiniMax H3 / Qwen-Image Turbo”章节。普通网页抓取缓存未包含此章节，直接带缓存刷新参数请求获得HTTP200的新文档后再核对实现。只修改Comfyui-zhenzhen，没有修改其他插件。

## 参数区别

MiniMax H3 ComfyUI Max提交与查询使用 `/v1/video/generations`，不是旧MiniMax-H3的v2接口，也不是 `/v1/videos`。seconds为3-15整数字符串，默认5；resolution为480p、608p、768p、896p、1088p、1280p、1440p，默认480p；ratio仅16:9、9:16，默认16:9。

视频可不接素材，也可接最多9张有序图片与3段音频，图片和音频可以混用。图片单张不超过10MiB、总计不超过50MiB；音频总计不超过10MiB。本地IMAGE编码为保留RGB/RGBA的PNG，AUDIO编码为WAV。全部素材编码、尺寸/有限值/批次数量校验和总字节数校验完成后才上传。音频URL放在metadata.audio_urls，不伪装成视频参考或旧content协议。

视频seed只控制ComfyUI缓存，不发送给API。支持Fixed、Randomize、Increment、Decrement；固定输入复用缓存。

两个图像模型均提交与查询 `/v1/image/generations`，不接图片为文生图，接图片为编辑，每次输出一张。

| 参数 | MiniMax H3 Image | Qwen Image 2.1 Turbo |
| --- | --- | --- |
| 图片上限 | 16张 | 4张 |
| resolution | 1k、2k（默认）、4k | 1k（默认）、2k；编辑额外支持720p |
| ratio | 1:1、2:3、3:2、3:4、4:3、9:16、16:9、21:9、1:3、3:1 | 前八种，不含1:3与3:1 |
| output_format | jpeg（默认）、png、webp | 不发送此参数 |
| 原生seed | -1不发送；0-2147483647有效 | 同左 |
| 提示词限制 | 必须非空；不猜测未公布的长度限制 | 必须非空，最多8192个UTF-8字节 |

不向Qwen发送旧megapixels、n或output_format。720p在没有图片连接时不出现在下拉框，但保留已转换的外部resolution输入并在运行时严格校验。提示词等连接占位值在预校验时延后处理，实际运行仍拒绝空提示词。端口逐路展开，不删除或临时替换inputs数组，保留连接索引。

创建请求使用已有安全传输：不自动重放不确定的POST；查询与下载使用已有有界重试和共享可靠下载路径，保持120秒下载超时下限及更长配置，不禁用TLS、不新增truststore依赖。

## 实测

本次恰好创建三个任务，每个模型一个，均完成上传、提交、轮询、下载和完整解码。未反复提交已成功的请求。

| 任务 | 实测结果 |
| --- | --- |
| MiniMax H3 Image双图编辑，1k、WebP、seed=0 | 63.05秒，1024x1024 RGB；本地保存PNG为339241字节 |
| Qwen Turbo双图编辑，720p、seed=0 | 36.05秒，736x736 RGB；本地保存PNG为375563字节 |

PNG字节数是对节点解码结果重新保存后的大小，不代表原始WebP等上游文件大小。实际输出尺寸以返回文件为准，不能把720p档位声称为精确720x720。

另外复用参考项目六条已完成响应，运行本插件的实际解析、下载和解码：两个图片模型各文生/双图编辑、视频文生/图音混合。回放不是六次新的上游生成；纯图片/纯音频视频示例的画布执行复用已完成混合结果，不等同于分别进行了新的上游模式实测。最大素材数量和高分辨率档位仅做离线与画布边界验证，没有提交上限数量的真实请求。
